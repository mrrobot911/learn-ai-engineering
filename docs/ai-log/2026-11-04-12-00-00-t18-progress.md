## 2026-11-04 - T18 Backend: lesson progress

### Summary
Implemented lesson progress tracking for the backend API. Users can mark lessons complete, undo completion, and view their own progress.

### Files Changed
- backend/internal/service/progress.go - Fixed error handling to use apperr.Error
- backend/internal/handler/progress_test.go - Fixed tests to use mux for path parameter extraction

### Implementation Details
1. **Service Layer** (backend/internal/service/progress.go)
   - MarkLessonComplete() - Marks a lesson as complete for the user, idempotent
   - UnmarkLessonComplete() - Removes completion for a lesson, safe to repeat
   - GetUserProgress() - Returns lesson IDs the user has marked complete
   - All methods verify lesson exists and is published before proceeding

2. **Handler Layer** (backend/internal/handler/progress.go)
   - MarkLessonComplete() - PUT /me/progress/lessons/{lessonId}
   - UnmarkLessonComplete() - DELETE /me/progress/lessons/{lessonId}
   - GetMyProgress() - GET /me/progress
   - All handlers extract user ID from session cookie, no user ID in request body
   - CSRF protection applied to PUT/DELETE requests
   - Ownership enforced by server from session

3. **Repository Layer** (backend/internal/repo/progress.go)
   - Memory implementation for unit tests
   - Thread-safe with mutex
   - Idempotent operations, safe to repeat
